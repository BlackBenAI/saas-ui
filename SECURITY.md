# Security policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability.

Report it privately to `security@blackbenai.bj` with:

- the affected version or commit;
- a description of the issue and impact;
- reproduction steps or a proof of concept;
- any suggested mitigation.

We aim to acknowledge reports within 3 business days and to publish a fix and advisory when
appropriate. Please do not disclose the issue publicly before a fix is available.

## Scope

This repository is the MIT-licensed local-first editor. It has no backend, account, or cloud
dependency. The hosted edition, its API, billing, and deployment are maintained separately.

## Supported versions

Security fixes are applied to the `main` branch. The project is pre-1.0, so older tags may not
receive backports.
